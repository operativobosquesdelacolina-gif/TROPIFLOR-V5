# TROPIFLOR – PRODUCTION CONTROL v1.5
1. Sube todo este contenido (incluida la carpeta .github) a un repositorio de GitHub, rama main.
2. Actions > Build APK > descarga el artefacto "tropiflor-apk" (app-release.apk).
3. Instala sobre la app anterior: la base de datos se migra sola a la versión 4 y conserva todos los datos.
4. Incluye la nueva pestaña "Plano" (20x30 con zoom, paredes en negro, colores por empresa/carga y borrador), además de exportación/importación en Excel.
